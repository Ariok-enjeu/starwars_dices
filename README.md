## Fonctionnalités

- 🎲 Réserve de dés du **joueur** et réserve du **Maître du Jeu**
- 🎲 Lancer en un seul bouton
- 🔄 Bouton **Reset** pour repartir de zéro
- 📴 Fonctionne **sans connexion** une fois installée
- 📱 Plein écran sur mobile, comme une application native
- 🌑 Interface sombre, adaptée à la table de jeu

---

## Utilisation rapide

1. Ouvrez <https://ariok-enjeu.github.io/starwars_dices/> dans votre navigateur.
2. Composez la **réserve du joueur**.
3. Composez la **réserve du Maître du Jeu**.
4. Touchez **🎲 LANCER**.
5. Touchez **Reset** pour vider les réserves.

> Cette méthode demande une connexion à chaque ouverture. Pour jouer hors ligne, installez l'application (voir ci-dessous).

---

## Installation sur iPhone / iPad (Safari)

1. Ouvrez le lien dans **Safari**.
2. Attendez le chargement complet de la page.
3. Touchez le bouton **Partager** (carré avec une flèche vers le haut), en bas de l'écran.
4. Faites défiler et choisissez **Sur l'écran d'accueil**.
5. Gardez le nom proposé (**Dés SW**) ou modifiez-le, puis touchez **Ajouter**.
6. Lancez l'application depuis l'icône ajoutée à l'écran d'accueil.

L'application s'ouvre en plein écran, sans barre d'adresse.

## Installation sur Android (Chrome)

1. Ouvrez le lien dans **Chrome**.
2. Touchez le menu **⋮** en haut à droite.
3. Choisissez **Installer l'application** (ou **Ajouter à l'écran d'accueil** selon la version).
4. Confirmez avec **Installer**.
5. Lancez l'application depuis l'icône ajoutée.

Chrome peut aussi proposer de lui-même une bannière « Installer l'application » à la première visite.

## Installation sur ordinateur (Chrome / Edge)

Une icône d'installation (écran avec une flèche) apparaît à droite de la barre d'adresse. Cliquez dessus, puis sur **Installer**.

---

## Vérifier le mode hors ligne

1. Après l'installation, **ouvrez l'application une première fois avec Internet** : elle met alors ses fichiers en cache.
2. Fermez complètement l'application.
3. Activez le **mode avion**.
4. Relancez l'application depuis son icône.

Si elle s'affiche et que les lancers fonctionnent, vous pouvez jouer sans réseau.

## Mises à jour

Lorsque l'appareil est connecté, l'application récupère automatiquement la dernière version en arrière-plan. Si une nouveauté n'apparaît pas tout de suite, **fermez complètement l'application et rouvrez-la** (parfois deux fois) avec une connexion active.
