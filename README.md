# ★ Dés Star Wars ★

Calculateur et lanceur de dés narratifs pour Star Wars (Edge of the Empire / Age of Rebellion / Force and Destiny).

Gère la réserve de dés (Aptitude, Maîtrise, Fortune, Difficulté, Défi, Infortune), lance les dés et résout automatiquement les symboles (Succès, Échec, Avantage, Menace, Triomphe, Désastre).

## Utilisation

Ouvrez simplement [index.html](index.html) dans un navigateur, ou installez l'app depuis sa version hébergée (PWA installable : icône sur l'écran d'accueil, plein écran, fonctionne hors-ligne).

## Développement

Fichiers statiques uniquement (HTML/CSS/JS), aucune dépendance ni étape de build.
